

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/11Vg5ivGJT1y_MjtyepI4jLhWBupdOuka

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `CONTACT_SCRIPT_URL = " enter the url "` in [.env.local](.env.local) to your  API key
3. Run the app:
   `npm run dev`
